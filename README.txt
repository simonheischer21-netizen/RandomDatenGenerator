RandomDaten-Generator v1.0
==========================

Installation:
1. Entpacke den Ordner.
2. Doppelklick auf install.bat  (erstellt Desktop-Verknuepfung).
3. Auf den Desktop klicken und generieren.

Hinweise:
- Benoetigt Python 3.x (python.org, Haken bei "Add Python to PATH").
- Keine zusaetzlichen Pakete noetig (nur Standardbibliothek).
- Alle generierten Werte sind pro Sitzung garantiert einzigartig
  (Dedupe ueber interne Datenbank + riesiger Kombinationsraum).
